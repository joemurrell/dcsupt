How To Use This Site

RTFM // PILOT BRIEF

If you're new to DCS

Start with Phase 0 — get your sim configured, controls bound, and the basic environment running. Then move into Phase 1 (IQT) to build airmanship before you ever touch a weapon.

If you already fly DCS

Use the phase pages as a syllabus check. Even experienced sim pilots find gaps when measured against a structured pipeline — that's the point.
